【描述】
------------------------------------------------------------
把 AI 编程订阅的额度装进口袋。

Coding Plan Monitor 实时监控你的 Coding 订阅用量，支持 GLM Coding、Kimi Coding、Claude Code、OpenAI Codex、火山引擎、通义、MiniMax、GitHub Copilot、Gemini CLI、DeepSeek 共 10 家供应商，多账号同时管理。

• 用量一览：5 小时 / 每周 / 每月额度圆环与进度条、重置倒计时、MCP 调用次数、DeepSeek 余额
• 主屏幕小组件 + 灵动岛：额度告急时锁屏常驻倒计时
• 智能提醒：用量超 80% / 95% 告警、重置完成通知、每周用量报告、余额预警
• 用量趋势：历史曲线与一键分享卡片
• iCloud 同步：账号配置与凭证在 iPhone / iPad / Mac 间自动同步
• 隐私优先：不收集任何数据，凭证仅存储于本机 Keychain

需要相应平台的订阅账号及 API Key / OAuth Token 才能使用。
